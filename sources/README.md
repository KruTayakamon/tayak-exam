กติกา
- เก็บเฉพาะ**หนังสือราชการและประกาศทางการ** (หลักเกณฑ์ หลักสูตร ปฏิทิน) เพื่อให้ตัวที่มาทำต่อเปิดอ่านได้โดยไม่ต้องค้นใหม่
- **ห้ามเก็บข้อสอบ ข้อสอบที่จำมา หรือไฟล์แนวข้อสอบของผู้อื่นใน repo นี้** (เส้นแดง)
- ทุกไฟล์ต้องมีแถวในตารางด้านล่าง: เลขหนังสือ วันที่ของเอกสาร ที่มา วันที่ดาวน์โหลด
- เว็บ ก.ค.ศ. (otepc.go.th) ปิดกั้นการเข้าจากต่างประเทศ เครื่องของ Claude เปิดไม่ได้ จึงใช้สำเนาฉบับสแกนที่เว็บข่าวการศึกษานำมาเผยแพร่ · ถ้าบอสดาวน์โหลดจากต้นทางได้ ให้แทนไฟล์และแก้ตาราง

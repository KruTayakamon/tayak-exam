# แผงควบคุมของเจ้าของ (owner panel) · 16 พ.ย. 2569 (บอสสั่งเพิ่ม)

ต้นแบบหน้าจอ: `design/owner_prototype.html` · ฝั่งเซิร์ฟเวอร์: `supabase/functions/exam-admin/index.ts` · ตาราง: `supabase/sql/2026-11-16_exam_admin.sql`
**สถานะ: ร่างไฟล์ครบ ยังไม่ได้รัน SQL ยังไม่ได้ deploy ยังไม่มีหน้าเว็บจริง** (หน้าเว็บ `/owner/` สร้างพร้อมโครงเว็บในเรื่องยากข้อ 4)

## 1. ใครเข้าได้
- เฉพาะ**อีเมล 2 บัญชีของบอส** ที่ล็อกอินด้วย Google ผ่านระบบล็อกอินเดียวกับผู้เรียน
- รายชื่ออีเมลเจ้าของ**ไม่อยู่ใน repo และไม่อยู่ในฐานข้อมูล**: บอสตั้งเป็น secret ชื่อ `EXAM_OWNER_EMAILS` ใน Supabase (สองอีเมลคั่นด้วยจุลภาค) เปลี่ยนรายชื่อได้โดยไม่ต้องแก้โค้ด
- เซิร์ฟเวอร์ตรวจทุกคำขอ: ต้องมี session + อีเมลยืนยันแล้ว + อยู่ในรายการ มิฉะนั้นได้ 403 · หน้า `/owner/` เป็นไฟล์สแตติกที่ไม่มีข้อมูลใด ๆ ในตัว คนอื่นเปิดได้แต่เห็นแค่ปุ่มล็อกอินและข้อความ "ไม่มีสิทธิ์"
- ไม่มีลิงก์ไปหน้า `/owner/` จากหน้าใดของเว็บ และตั้ง `noindex`

## 2. สิ่งที่เจ้าของควบคุมได้
| หมวด | ทำอะไรได้ | action ฝั่งเซิร์ฟเวอร์ |
|---|---|---|
| **ภาพรวม** | รายได้วันนี้ 7 วัน 30 วัน · จำนวนขายตามสินค้า · เส้นทางสู่การจ่าย (ทำแบบวัดระดับ → เริ่มคอร์ส → จ่าย) · ผู้เรียนที่เรียนใน 7 วัน · สิ่งที่ต้องดูวันนี้ (ค้างจ่าย รายงานข้อผิด เนื้อหารอตรวจ) | `overview` |
| **คำสั่งซื้อและสิทธิ์** | ค้นด้วยอีเมล · ดูคำสั่งซื้อ · ถาม Beam ว่ารายการค้างจ่ายแล้วหรือยังแล้วให้สิทธิ์ · ให้สิทธิ์ฟรีหรือต่อเวลา (ทีมงาน ผู้ทดสอบ ชดเชย) · เพิกถอนสิทธิ์ · บันทึกว่าคืนเงินแล้ว | `orders` `order_verify` `grant` `revoke` `refund_mark` |
| **เนื้อหา** | อ่านข้อพร้อมเฉลย · อนุมัติ ส่งกลับแก้ หรือถอดออกทันที (รายข้อหรือทั้งสัปดาห์) · อ่านและปิดรายงานข้อผิดจากผู้เรียน · ดูอัตราตอบถูกครั้งแรกของแต่ละข้อ | `content_list` `content_status` `week_status` `reports` `report_close` `item_stats` |
| **ราคาและการตั้งค่า** | แก้ราคาปกติและราคาเปิดตัวรายสินค้า · กำหนดวันสิ้นสุดราคาเปิดตัว · เปิดปิดการขายรายสินค้า · ป้ายประกาศบนเว็บ · โหมดปิดปรับปรุง (หยุดขาย ผู้มีสิทธิ์ยังเรียนได้) | `settings_get` `settings_set` |
| **ผู้เรียน** | ดูความคืบหน้าของผู้เรียนหนึ่งคนเพื่อช่วยเหลือ · ลบข้อมูลการเรียนตามคำขอ (ต้องพิมพ์อีเมลซ้ำ) | `learner` `learner_delete` |
| **ประวัติ** | ทุกการกระทำที่เปลี่ยนข้อมูล: ใคร ทำอะไร เมื่อไร ค่าเดิมและค่าใหม่ | `log` |

## 3. กติกาป้องกันความผิดพลาด
1. **ราคา:** รับเฉพาะจำนวนเต็ม 20–5,000 บาท และราคาเปิดตัวต้องไม่เกินราคาปกติ (กันพิมพ์ผิดหลัก) · มีผลกับคำสั่งซื้อใหม่เท่านั้น คำสั่งซื้อที่สร้างแล้วเก็บราคา ณ ตอนนั้น · ค่าตั้งต้นอยู่ในโค้ด (`engine/pricing.mjs`) ค่าที่ตั้งในแผงทับค่าตั้งต้น
2. **มติราคายังเป็นของบอส:** การแก้ราคาในแผงคือการตัดสินใจของบอสเอง Claude ไม่มีสิทธิ์เข้าแผงและไม่แก้ราคาแทน
3. **เนื้อหา:** ผู้เรียนเห็นเฉพาะข้อและสัปดาห์ที่สถานะ `approved` · "ถอดออก" มีผลทันทีสำหรับข้อที่มีคนรายงานว่าเฉลยผิด · การอนุมัติในแผงเปลี่ยนสถานะในฐานข้อมูล และ `tools/make_seed_sql.py` **ไม่เขียนทับสถานะของข้อที่มีอยู่แล้ว** (เว้นแต่สั่ง `--force-status`) การนำเนื้อหาที่แก้แล้วเข้ารอบถัดไปจึงไม่ล้างการอนุมัติของบอส · ข้อที่แก้เนื้อหาหลังอนุมัติ ผู้ดูแลเนื้อหาต้องแจ้งบอสให้ตรวจซ้ำ
4. **คืนเงิน:** แผงไม่โอนเงิน บอสโอนคืนเองก่อนแล้วจึงกด "บันทึกว่าคืนเงินแล้ว" ซึ่งเปลี่ยนสถานะคำสั่งซื้อและเพิกถอนสิทธิ์
5. **ลบข้อมูล:** ลบได้ทีละคน ต้องพิมพ์อีเมลซ้ำ ลบเฉพาะข้อมูลการเรียน คำสั่งซื้อเก็บไว้ · ไม่มีการลบแบบหลายคน
6. **ดูข้อมูลผู้เรียน:** ทุกครั้งที่เปิดดูถูกบันทึกในประวัติ (ตามหลักเก็บและเข้าถึงข้อมูลเท่าที่จำเป็น)
7. **สิ่งที่แผงทำไม่ได้โดยเจตนา:** แก้คะแนนหรือความคืบหน้าของผู้เรียน · แก้โจทย์และเฉลย (แก้ที่ไฟล์ใน repo เพื่อให้ผ่านตัวตรวจ) · ดูงานเขียนหรือเสียงของผู้เรียน (ไม่ได้เก็บ)

## 4. สิ่งที่บอสต้องทำเมื่อพร้อมใช้
1. รัน `supabase/sql/2026-11-16_exam_core.sql` แล้วตามด้วย `supabase/sql/2026-11-16_exam_admin.sql` ใน SQL Editor
2. Supabase → Edge Functions → Secrets → เพิ่ม `EXAM_OWNER_EMAILS` ใส่อีเมลเจ้าของ 2 บัญชี คั่นด้วยจุลภาค ไม่มีช่องว่าง
3. deploy ฟังก์ชัน `exam-admin` (พร้อม `exam-api` และ `exam-billing`)
4. เปิดหน้า `/owner/` ล็อกอินด้วย Google บัญชีใดบัญชีหนึ่งในสองบัญชี

## 5. งานที่เหลือ
- หน้าเว็บ `/owner/` ตามต้นแบบ 5 จอ (สร้างพร้อมโครงเว็บ)
- `exam-api` ต้องกรองให้ผู้เรียนเห็นเฉพาะเนื้อหา `approved` และเคารพโหมดปิดปรับปรุง (ตอนนี้ยังไม่ได้กรองในเส้นทาง `session`)
- ส่งออกรายการคำสั่งซื้อเป็นไฟล์ตาราง (สำหรับทำบัญชี)
- ทดสอบจริงหลัง deploy: บัญชีที่ไม่ใช่เจ้าของเรียกทุก action ต้องได้ 403

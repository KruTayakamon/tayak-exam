# แอปผู้เรียน: โครงหน้าเว็บและตัวเล่นเซสชัน (16 พ.ย. 2569)

**สถานะ:** แอปผู้เรียนทำงานได้ครบวงในรุ่นสาธิต (เซิร์ฟเวอร์จำลองในเบราว์เซอร์) และมีเทสต์อัตโนมัติ 34 ข้อผ่าน · **ยังไม่ได้ต่อกับเซิร์ฟเวอร์จริง** (ยังไม่มีล็อกอิน ยังไม่มีการจ่ายเงินจริง) · หน้าสาธารณะ (หน้าแนะนำ แบบวัดระดับ) และหน้า `/owner/` ยังไม่ได้สร้าง

## 1. โครง
| ที่ | หน้าที่ |
|---|---|
| `web/app.html` | เปลือกของแอปผู้เรียน (หน้าเดียว เปลี่ยนจอด้วย `#`) |
| `web/css/app.css` | ระบบภาพจากต้นแบบ · สีและตัวอักษรเป็นตัวแปร รองรับโหมดมืด · ขนาดตัวอักษร 3 ระดับ |
| `web/js/app.js` | เส้นทาง: `#today` `#course` `#extra` `#results` `#buy` `#account` `#session-full` `#session-short` · แถบล่าง 4 แท็บ (ซ่อนระหว่างเซสชัน) |
| `web/js/views.js` | จอนอกเซสชัน: ตั้งแผน วันนี้ คอร์ส ฝึกเพิ่ม ผล ราคา บัญชี |
| `web/js/player.js` | **ตัวเล่นเซสชัน** (หัวข้อ 2) |
| `web/js/items.js` | ตัวแสดงข้อ 6 ชนิด: เลือกตอบ พิมพ์คำ เรียงประโยค ข้อความมีช่องว่าง บทอ่าน บทฟัง · ตัวเลือกเป็น 1 2 3 4 |
| `web/js/store.js` | ที่เก็บในเครื่อง: เซสชันที่ค้าง คิวคำตอบ ค่าที่ผู้เรียนตั้ง (ทุกจุดห่อ try/catch) |
| `web/js/api.js` | จุดเดียวที่หน้าเว็บขอข้อมูล: เลือก `api_demo.js` (เมื่อมี `DEMO_DATA`) หรือ `api_remote.js` |
| `web/js/api_demo.js` | เซิร์ฟเวอร์จำลอง ใช้ `engine/` ตัวเดียวกับของจริง พฤติกรรมต้องตรงกับ `exam-api` |
| `web/js/api_remote.js` · `config.js` | ตัวต่อเซิร์ฟเวอร์จริง (โครง ยังไม่เคยรัน) และค่าสาธารณะของเว็บ |
| `build.py` | `dist/` เว็บจริง · `--demo` → `dist-demo/` · `--bundle` → `build/demo_bundle.html` (ไฟล์เดียวสำหรับ artifact) |
| `tests/test_app.js` | เทสต์เส้นทางหลักที่จอ 390 (หัวข้อ 4) |

กติกา: โค้ดใน `web/js/` ใช้ `import { ชื่อ } from './ไฟล์.js'` และ `export function/const` เท่านั้น (ไม่มี default export ไม่มี alias) เพราะตัวรวมไฟล์เดียวใน `build.py` รองรับเท่านี้ และจะหยุดพร้อมข้อความถ้าเจอรูปแบบอื่น · ตรรกะการเรียนทั้งหมด import จาก `js/engine/` (สำเนาจาก `engine/` ตอน build) ห้ามเขียนซ้ำ

## 2. ตัวเล่นเซสชัน
1. ขอแผนจากเซิร์ฟเวอร์ (`api.session`) ได้ `plan.steps` + ข้อที่ใช้พร้อมเฉลย → `flatten()` แปลงเป็นรายการ "การ์ด" เรียงตามที่ผู้เรียนเห็น (ทบทวน → บทเรียน → เช็ก 2 ข้อ → ฝึก → ใช้ → สรุป · หรือห้องฝึก · หรือชุดย่อย)
2. **ทำต่อจากที่ค้าง:** ทุกครั้งที่ขยับการ์ด เก็บทั้งเซสชัน (แผน ข้อ ตำแหน่ง คะแนน) ลงเครื่อง · กดออกหรือโหลดหน้าใหม่แล้วกลับมาที่การ์ดเดิม · ข้อที่ตอบแล้วไม่ถูกนับซ้ำ
3. **เฉลยทันที:** ตรวจในเครื่องด้วย `grade.mjs` (ตัวเดียวกับเซิร์ฟเวอร์) แล้วแสดงเหตุผลของทุกตัวเลือก · ข้อเดี่ยวที่ตอบผิดบอกว่า "จะกลับมาให้ทบทวนพรุ่งนี้"
4. **คิวคำตอบ:** แต่ละคำตอบเป็นเหตุการณ์ `{eid, item, q, answer, mode, ts}` เก็บในเครื่องก่อน แล้วส่งเบื้องหลังหลังทุกข้อ (`flush`) · เซิร์ฟเวอร์รับแล้วจึงลบจากคิว · เน็ตหลุดก็เรียนต่อได้ คิวจะถูกส่งเมื่อกลับมาออนไลน์หรือเปิดแอปครั้งถัดไป
5. **จบเซสชัน:** ส่งคิวที่เหลือพร้อม `completed` · **ไม่ล้างเซสชันในเครื่องจนกว่าเซิร์ฟเวอร์ตอบรับ** (ถ้าบันทึกไม่สำเร็จ ปุ่มเปลี่ยนเป็น "แตะเพื่อลองใหม่") · เซิร์ฟเวอร์เป็นผู้ขยับตัวชี้บทเรียน
6. บทฟังใช้เสียงอ่านของเครื่อง ฟังได้ 2 ครั้ง มีปุ่มฟังช้า · เครื่องที่ไม่มีเสียงอ่านจะแสดงบทให้อ่านแทน · ตอบครบแล้วแสดงบทฟังเสมอ
7. ขั้น "ใช้" และห้องฝึก: ผู้เรียนพิมพ์เอง เทียบกับคำตอบตัวอย่าง มีรายการตรวจตนเอง · ข้อความที่พิมพ์ไม่ถูกส่งไปไหน

## 3. รุ่นสาธิต
- `python3 bank/build.py && python3 build.py --demo` แล้วเปิด `dist-demo/app.html` ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง (เปิดเป็นไฟล์ตรง ๆ ไม่ได้เพราะเบราว์เซอร์กันโมดูล)
- `python3 build.py --bundle` → ไฟล์เดียว publish เป็น artifact ส่วนตัวให้บอสลองบนมือถือ (ลิงก์ใน CLAUDE.md)
- หน้าบัญชีของรุ่นสาธิตมีปุ่ม "ข้ามไปวันถัดไป" (ดูการทบทวนข้อที่ผิด) และ "ล้างข้อมูลสาธิต"
- รุ่นสาธิต**มีเฉลยฝังอยู่** จึงอยู่ใน `dist-demo/` และ `build/` ซึ่งไม่ commit และห้าม deploy · `tests/test_bank.py` ตรวจว่า `dist/` ไม่มีรหัสข้อ ตัวเลือก หรือข้อมูลสาธิต

## 4. เทสต์ (`node tests/test_app.js`)
ตั้งแผน → วันที่ 1 → ตอบผิดโดยเจตนา → เห็นเหตุผลครบ 4 ตัวเลือกและเลข 1–4 → กดออกแล้วทำต่อ → โหลดหน้าใหม่แล้วอยู่ขั้นเดิม → สรุปนับ 12 ข้อไม่ซ้ำ → ตัวชี้เป็นวันที่ 2 → เซิร์ฟเวอร์จำลองได้ 12 เหตุการณ์และคิวว่าง → ข้ามวัน → เซสชันสั้นมีแต่ข้อที่ผิด ไม่ขยับบทเรียน ข้อเลื่อนเป็นขั้น 2 → วันที่ 2–6 ครบทุกชนิดข้อ → จบสัปดาห์ → ทุกจอไม่ล้นที่ 390 → รุ่นไฟล์เดียวเล่นได้ → เว็บจริงไม่มีข้อมูลฝังและเปิดได้ → ไม่มีข้อผิดพลาดในคอนโซล

## 5. งานที่เหลือ (เรียงตามลำดับที่ควรทำ)
1. **ล็อกอิน Google และต่อเซิร์ฟเวอร์จริง:** เติม `api_remote.js` (supabase-js) ตามแนว `cloud` ของเกมครัว · ทำหลังบอสอนุมัติและรัน SQL · ต้องเทียบพฤติกรรมกับ `api_demo.js` ทีละเส้นทาง
2. **หน้าสาธารณะ:** หน้าแนะนำ (มี Open Graph) · แบบวัดระดับ 25 ข้อและหน้าผล · หน้าซื้อที่ต่อ Beam · นโยบายความเป็นส่วนตัวและข้อกำหนด
3. **หน้า `/owner/`** ตามต้นแบบ 5 จอ (`docs/cefr/06_owner_panel.md`)
4. ชุดย่อยวันที่ 6 แบบจับเวลา (รอข้อสำรอง) · ชุดวัดผล 3 ครั้ง · หน้าฝึกเพิ่มและสมุดข้อผิด · ใบบันทึกการพัฒนาตนเอง
5. อัดเสียงตัวเองในห้องฝึกพูด (เก็บในเครื่อง) · ปุ่มเพิ่มนัดลงปฏิทิน · ติดตั้งเป็นแอปบนหน้าจอ
6. รายงานข้อ: ตอนนี้ส่งเหตุผลเป็น "อื่น ๆ" เสมอ ต้องเพิ่มตัวเลือกเหตุผล 5 แบบตามตาราง `exam_reports`
